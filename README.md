# NEON DROP — AI 3D 에셋 게임용 정리

제 1차 성취도 평가 · 블렌더 기초 (AI 에셋 게임용 정리)
훈련생: 오승민 · 훈련과정: 2026 대전 KNDA 게임 개발 과정

VARCO 3D로 생성한 **캐릭터 1종 + 소품 1종 + 배경 2종**을 Blender로 정리하고 Unity에서 정리 전·후를 비교해 검증한 결과물입니다.
4종 합계 삼각형 **200,000 → 21,084 (-89.5%)**.

**포트폴리오 PDF:** [`01_오승민/docs/01_블렌더기초_오승민.pdf`](01_오승민/docs/01_블렌더기초_오승민.pdf)

## 폴더 구성 (`01_오승민/`)

| 폴더 | 내용 |
|---|---|
| `Robot/`, `Box/`, `Lamp/`, `Building/` | 정리 후 FBX + 텍스처(`*.fbm/`: BaseColor·Normal·Metallic·Roughness, 4096) |
| `before/` | 정리 전 FBX 5개 (VARCO 원본, 비교용) + 텍스처 |
| `captures/` | Blender·Unity 정리 전·후 비교 캡처 |
| `docs/` | 포트폴리오 PDF, 작업 기록(`작업기록.md`) |

## Unity에서 가져올 때

개발·검증 환경: Unity 6 (URP).
텍스처가 기본 설정으로 줄어들거나 압축되어 얼룩이 생기지 않도록 아래처럼 설정했습니다.

- 텍스처 최대 크기 **4096**, 압축 **고품질(BC7)**
- Normal 텍스처는 Texture Type을 **Normal map**으로 지정
